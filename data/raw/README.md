# Raw data

Run `python src/download_data.py` from the repository root. Downloaded files are kept locally and excluded from Git. The source URLs, original retrieval dates and checksums are in `data/metadata/`. The report contains descriptive summaries and charts, not a redistributed market-data archive.

The report uses the daily snapshot collected on 4 November 2026 and the intraday examples downloaded on 19 November 2026. Live downloads can change as sources revise or extend their files. Check their sample counts against the saved snapshot metadata before replacing the report.
